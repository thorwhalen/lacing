lacing.model

Annotation envelope, references, and provenance.

One envelope, typed body. The body: dict is validated by the schema at body_schema_uri (semver). No polymorphic class hierarchy. See BACK-DOC §2.1 and .claude/skills/lacing-schema-codegen/SKILL.md.
