lacing.bodies.named_entity

Body schemas for named-entity (NER) annotations.

URIs:

annot://schema/named-entity/v1 – type + text annot://schema/named-entity/v2 – entity_type + text + optional confidence (additive)

A v1 -> v2 migration is registered to demonstrate the pattern.

class lacing.bodies.named_entity.NamedEntityBodyV1(*, type: str, text: str)[source]

Original NER body. type is the entity tag (PER, ORG, LOC, …).

model_config = {'extra': 'forbid', 'frozen': True}

Configuration for the model, should be a dictionary conforming to [ConfigDict][pydantic.config.ConfigDict].

class lacing.bodies.named_entity.NamedEntityBodyV2(*, entity_type: str, text: str, confidence: Annotated[float | None, Ge(ge=0.0), Le(le=1.0)] = None)[source]

v2 renames type -> entity_type and adds optional confidence.

The rename makes v2 incompatible with v1, so we register a migration.

model_config = {'extra': 'forbid', 'frozen': True}

Configuration for the model, should be a dictionary conforming to [ConfigDict][pydantic.config.ConfigDict].
